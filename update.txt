Warlords Redux 2.8 Patch 15

Assets
* (New) MH-80 DAP.
* (New) Taru Rally Deployer.
* Fighting position: resilient to damage.
* Kuma: added AP smart mines for close defense.
* Rhino: improved wheel survivability against impact.
* Slammer: cost $5,800->5,500, integral mortar ammo 8->24.
* Slammer UP: cost $6,500->7,500.

Gameplay
* Added reinforcements explanation subtitle to hud.
* Adding supplies to sector no longer boosts stronghold if intruders are present inside.
* Aircraft notching of weak missiles now easier at short range.
* Camera and radar pods added to pylon options: Ghosthawk II, Pawnee, Hellcat, Orca, Wipeout, Buzzard, Gryphon.
* Base flag is now a billboard that is easier to rearm from, now also has frontline action.
* Carrier now spawns static defenses instead of infantry, should be much faster to capture for a coordinated team.
* Decreased night time length.
* Directly disabled drawing to global.
* Enemy team's attack target sector is revealed when friendly player enters the sector.
* Enemy team's home base is revealed when friendly player enters the sector.
* Locked doors now auto-start unlocking animation and inform player about explosive entry.
* Paradrop now uses parachute for most of the fall.
* Removed fuel tank pylon options.
* Removed radome scanning animation.
* Securing enemy discovers a random enemy sector, revealing it if previously un-revealed.
* Slingload short rope length 6->10m.
* Starstreak launcher vehicles now deploy ramps.
* Usability enhancements for air defense map layer.

* Fixed forced cargo in inventory for objects without containers.
* Fixed demolition explosive charges tip showing on minefields.
* Fixed enemy radome arc being invisible.
* Fixed Huron/Mohawk Supply being spawnable in helipad sector under attack.
* Fixed integral weapons not saving stats.
* Fixed large numbers of deployed structures giving spot rewards.
* Fixed magazine tooltip APS description error.
* Fixed missing loadouts on vehicle spawn.
* Fixed obstacle destruction repeating on collision.
* Fixed obstacles being populated into asset list.
* Fixed player setup resource leak.
* Fixed reset vehicle Russian localization.
* Fixed scanner UAV not cleaning up.
* Fixed script error on squad join.
* Fixed SEAD profile messaging issues.
* Fixed Slammer UP cannon second-stage shell being detonated on foliage.
* Fixed units drawing beneath minefields on map.
* Fixed wrecks remaining on map with no salvage value after player disconnect.
* Improved laser tracking performance.
