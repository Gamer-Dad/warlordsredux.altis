Warlords Redux 2.8 Patch 17

Gameplay
* Bunker enemy map visible distance: 100->500 m.
* Handheld AT now consumes 2x APS ammo: NLAW, Titan AT, Vorona HEAT, RPG-42 AT, MAAWS HEAT.
* Income bonus no longer boosts kill money.
* Laser guided munitions range: 20->12 km, consumes 3->2 APS, now stopped by device.
* Minefields now show as their team's color.
* Raised rearm max height 20->25m.
* Scoreboard now shows players if disconnected.
* Spawn tent and rally, enemy map visible distance: 100 m.
* Supply and supply MRAP, enemy map visible distance: 100->500 m.
* Supply drop max fall speed 50->25 m/s.
* UI display for APS depletion.

Bugfixes
* Fixed AI prematurely firing railguns.
* Fixed air defense help text being outdated.
* Fixed capsules not being shown on map.
* Fixed enemy capture notifications revealing unrevealed sectors.
* Fixed enemy target markers staying hidden after sector revelation and incorrect rotation when both teams select the same sector.
* Fixed friendly fire forgiveness prompts showing the killer's name instead of the victim or asset owner's name.
* Fixed hexagon sector FOB range limits.
* Fixed scoreboard script error when display ended before render is complete.
* Fixed some cases where player group is not successfully updated to the right side.
* Fixed target reset voting hiding the enemy target marker.
* Fixed team balancer not working exceptions.
* Fixed wrong endgame faction text.
* Fixed Xian drone deployer instantly destroying the Xian.
* Reworked buy menu for more efficient condition checks.
