Warlords Redux 2.8 Patch 18

Asset
* (Added) Tank decoys
* (Removed) Hunter/Ifrit Mortar
* (Removed) Mk30 HMG/Mk32 GMG (low)
* (Removed) Rectangular Minefield
* Bunker Hawk: bunker busters 3->5, added an additional 12.7mm gun.
* Caesar, Taru: bunker deployments 4->2.
* Orca Bomber: bunker busters 3->5, added radar pod.
* Offroad (IED): APS removed.

Gameplay
* Added minimum rating requirement to artillery assets.
* Camera swivels towards damage source upon player down.
* Flare and missile rework.
* Field repair now allowed when fuel is low, emergency refuels vehicle.
* Item deployer: removed minimum drop height.
* Removed first person restriction in manual drone.
* Removed option to do allied demolitions.
* Side picker now shows name of players in lobby in tooltip.
* Stormbreaker/UPMK: no longer stopped by advanced APS.
* Tents are no longer damageable by teammates.

Bugfixes
* Fixed attachments jitter during heavy server load.
* Fixed edge cases of players spawning as green.
* Fixed reinforcements turning into uneven number shortly after sector changes ownership.
* Fixed script error when rendering scoreboard while busy.
* Reworked turret limit visualizer.
