Warlords Redux 2.8 Patch 16

Assets
* (Added) Orca (Bunker Buster)
* (Removed) Marshall UP
* (Removed) Taru Rally Deployer
* Caesar: now deploys rally points.
* Marshall UP: loadout folded into Marshall.
* MH-80 DAP: cost increased $5,500->7,500, replaces vanilla loadout by default.
* Pawnee: 20mm gun changed to 127x99 HEIP.
* Radome: changed model and name to LR Radar.
* Static Mora: removed autonomous component.

Gameplay
* Added low altitude requirement for rearm.
* Added option to adjust capture interface top %.
* Atsalis jet spawning is now user-placed, RTB limited to a single position.
* Base billboard shows instructions.
* Increased available squad channels from 10->50.
* Map button for showing default stronghold location.
* Map markers reset when sector is revealed, reduces marker option pool to camped or none.
* No-fly zone shows distance on trigger.
* Player side selection is deferred after the lobby.
* Restock action now heals player to full health.
* Stronghold selection algorithm adjusted to favor larger buildings.
* Stronghold selection for green sectors now exclude destroyed buildings, allowing some sectors to be pre-cleared with explosives.
* Territory bonus is income, not capture modifier.

Bugfixes
* Fixed air radar scanning detecting aircraft at an altitude lower than it should.
* Fixed base billboard being moved.
* Fixed duplicate drawing of visible units on map.
* Fixed enemy scanned assets showing on my asset layer.
* Fixed enemy target selection VOs playing on neutral, revealed sectors.
* Fixed reinforcement bar showing for home bases.
* Fixed sector icon drawing for neutral, revealed sectors attacked by enemy.
* Fixed some instances of Xian/Bfish item deployer not triggering correctly. Deployers trigger on explosion.
* Fixed squad chat name becoming outdated when stealing voice slot.
* Fixed team priority being set to unlinked sector when enemy attacks.
* Fixed wrecks not detaching from dead carrier.
* Fixed Xian minelayer requirement conditions to bring it in line with the Blackfish.
* Optimized sector, vehicle spawning to use multi-threading.
* Optimized selected targets handler.
