* Euphrates: ammo reduced 8->6.
* Falcon: cost reduced $6,000->3,500.
* Fort/Supplies: now shows on map for enemies within 100m.
* Ghost: ammo reduced 16->12.
* Ghost Hawk (base): rearm time reduced 240->120s.

* Hummingbird: added fast travel point.
* Hunter AFV: added rearm capability.
* Hunter Apex: added rearm capability, added line charge.
* LR AA (Rhea/Defender): reduced notch immunity: 3,800->3,200m, damage reduced 100->80%.
* Marid Dragon: loadout reworked.
* Marshall UP: loadout folded into Marshall.
* MH-80 DAP: cost increased $5,500->6,500, replaces vanilla loadout by default.
* Medusa: ammo reduced 16->12.
* Orca Unarmed: rearm time reduced 240->120s, must be spawned in helipad sectors.
* Panther: switched 30mm for 127x99 HEIP.
* Pawnee: 20mm gun changed to 127x99 HEIP.
* Pelter: added LMG.
* Radome: changed model and name to LR Radar.
* Spartan/SAAMI: reduced notch immunity 3,000->2,500m, damage reduced 60->45%.
* Speedboat Armed: removed friendly sector requirement, replaced GMG with 12.7mm.
* Static Mora: removed autonomous component.
* Tents: now shows on map for enemies within 20m.

Gameplay
* Added low altitude requirement for rearm.
* Added option to adjust capture interface top %.
* Adjusted several sector locations to avoid placing base center inside building.
* Air assault into sector option now requires revealing the sector first.
* Atsalis jet spawning is now user-placed, RTB limited to a single position.
* Base billboard shows instructions.
* Deployers now drop straight with a parachute and show altitude on HMD.
* Factory production time increased: Slammer X (7.5->12), Rhino X (7.5->12), Futura (7.5->12), Dragon (5->10).
* Free airdrop no longer possible when vehicle was recently damaged.
* HUD now shows supplies in sector within 100m.
* Increased available squad channels from 10->50.
* Kill rewards reduced 20%.
* Manual SAMs are now stopped by APS without consuming APS ammo.
* Map button for showing default stronghold location.
* Map markers reset when sector is revealed, reduces marker option pool to camped or none.
* Naval ordering teleport now only activates once per life.
* No-fly zone shows distance on trigger.
* Player side selection is deferred after the lobby.
* Paradrop to sector: cooldown now 3 minutes, cost $500.
* Poll menu now opens on respawn until vote is cast.
* Railgun now does -1 structural damage if fully overheated (120%).
* Revamped structural damage icon.
* Restock action now heals player to full health.
* Reward multipliers reduced: first person (+100%->50%), PvP (+75%->25%)
* Squad leaders with more than 2,000 ELO can skip the squad number check when placing FOB.
* Sectors lose 80% of reinforcements upon changing ownership.
* Steam recording events support (optional).
* Stronghold selection algorithm adjusted to favor larger buildings.
* Stronghold selection for green sectors now exclude destroyed buildings, allowing some sectors to be pre-cleared with explosives.
* Supplies in sector can now be activated by enemies, reducing sector reinforcements by 10 each time.
* Supplies no longer have access control.
* Territory bonus is income, not capture modifier.
