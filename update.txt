Gameplay
* Added badges based on ELO.
* Added no-fly zone for home as a separate item in buy menu.
* Added setting to change volume for bird flocks on player TP, now only plays for enemies.
* Added stronghold instructions to HUD: can be disabled in settings.
* Added surrender message.
* Adding supplies to a sector will reset its stronghold cooldown timer and upgrade stronghold health, up to 24 max.
* Air wrecks: now combine if within 1km of another wreck, value shown on map.
* Airbase camper warning now restricts plane purchases at airbase by default, protection can be disabled in settings.
* Applied Blufor Gryphon customizations to green Gryphon.
* APS reload: all APS types can now be reloaded from outside the vehicle.
* Attack helicopters: removed device jammer on laser.
* Bulk deploy: rapid deployment of defense kits on map buttons.
* Camper warning now applies to vehicle purchases above $5,000.
* Cannon-launched missiles (non-LG) are now only stopped by advanced APS.
* Capture speed scaling based more closely on capture power difference.
* Changed custom building on map color from black to gray.
* Changed icons and colors for unknown sectors.
* Chat commands for help pages: !nfz, !aa, !capture
* Collaborator option: changed to allow control of vehicles on next sector, cost increased to $8,000.
* Conscription defaults to false for players who have already accepted, for the same priority, in the same life.
* Conscription shows destination in message.
* Death info display now persistent until player respawns.
* Damage for anti-air missiles should now be consistent, regardless of speed at time of hit.
* Default loadouts.
* Designate team priority: now free.
* Device APS and Advanced APS can now be reloaded inside vehicle by toggling it off, scroll wheel action for toggling APS.
* Drone EW now boosted by all enemy air wreck retrievals instead of just drone wrecks.
* ECM system start time decreased 10->5s.
* Enemies nearby lock radius 125->100m.
* Field repairs now work on helo rotors.
* Forward base now only considers infantry as intruders.
* Forward base upgrades now restricted to fob placer.
* Heavy+ APS renamed to Advanced APS.
* Helipads can be home base again.
* HMD now shows instance, altitude available on freelook button.
* HUD now shows missile tracking percent.
* HUD now uses arma 3 subtitling system for system messages, some additional subtitle options.
* Independent jets will now use countermeasures liberally.
* Laser-guided munitions: lock minimum altitude increased 50->100m.
* Losing a player sector now triggers an immediate sector vote reset.
* Mine clear charges: now demolish 1 step instead of directly deleting destructibles.
* Minefield warning: can be disabled or sensitivity adjusted in settings (default: 4 seconds ahead).
* Minor map balance changes, added more helipads.
* No-fly zone: minimum altitude increased 1,000->1,500m, cost reduced $8,000->5,000, cooldown reduced 20->16 minutes, duration increased 6->7 minutes, radius increased 6->7 km.
* Player vote power now ELO-boosted.
* Paradrop: unified under one free control system.
* Paradrop requests no longer default to true for infantry on foot.
* Priority selection is auto switched to defending sector when enemy starts attack on friendly sector.
* Punishment timer now shows hh:mm:ss to be more clear.
* Railgun: added HE damage.
* Reduced size of capture/vote interface.
* Sector reinforcement capture modifier now scales linearly based on number of reinforcements (0-5x), halves cap power when depleted.
* Sector reinforcement depletion no longer disables conscription.
* Sector reserves and reinforcements now shown in HUD.
* Sector total reinforcements reduced, income reduced from 5->3 per minute.
* Spawn menu cam now disabled when player is alive.
* Spawn menu refresh rate reduced from 5->1 Hz.
* Stronghold and forward base doors are now all locked to owner, can be forced open with explosives.
* Strongholds can now be created in sectors under attack, but destroyed strongholds will add a 5 minute timer.
* Strongholds now generate reinforcements for sectors under attack.
* Teamkilling timeout now 5 minutes, events persistent over longer time.
* Temporarily removed pylon descriptions to avoid confusion.
* Tents are now team-dependent rather than chemlight color dependent for easy team visual identification.
* Unconscious units are no longer seen on screen.
* Vehicle deployment above ground changed to deploy more precisely.
