Warlords Redux 2.7.0 Hotpatch 3

Balance
* Nyx AA now mounts 2 R77s instead of 8 Titan AA UPs.
* Caesar (Bomb) countermeasures removed, only carries 1 bomb.
* Halved helo-based ECM jammers or doubled recharge cooldowns.
* Reduced tent demolition time from 3->2s.
* Added dazzler to bomb drone, increased demolition power from 7->13.

Interface
* FOB circles no longer clog up map, only show if FOB/supply are highlighted by mouse.
* Add range warning to GPS guided munitions.
* Munition hints reset for different vehicles.
* Hints now display much more prominently, with a warning that they can be hidden in settings.
* Scoreboard auto scrolls to top instead of to player entry.

Gameplay
* When base vulnerable, spawn respawned players in neighboring sector, parachute only if completely cut.
* Drones now visible if being jammed.
* Vehicle magazine configurations are no longer saved.

Fixes
* Exploit that allows last version vehicle configs disabled.
* ECM jammer no longer sees unjammable cruise missiles.
* Scoreboard scroll up/down now working.
* Drones no longer visible on map for all players.
* Incapacitated players glitching over/into the ground.
* Enemies near player block conditions not correctly being applied.
* Destroyer ropes being misplaced on spawn.
* Destroyer VLS non-functional after respawning.

Performance
* Eliminated some client-side scripts on server.
* More efficient algorithm for calculating linked sectors.
* No longer send sector vote status unless changed.
* Reduced AI group radius while spawning.
* Increased AI spawn time gap.
